# Mental Health Analysis using BRFSS 2014 Dataset

A machine learning and data analysis project focused on examining behavioral health factors and mental health patterns (using the MENTHLTH variable) based on the BRFSS 2014 dataset.

## 📌 Project Overview
This project processes, cleans, and analyzes large-scale public health survey data to uncover insights related to mental health distribution and demographic differences.

## 🛠️ Tech Stack & Libraries
* Python
* Pandas & NumPy (Data manipulation and cleaning)
* Matplotlib & Seaborn (Data visualization)
* Jupyter Notebook (Development environment)

## 🧹 Data Preprocessing & Cleaning
* Loaded the BRFSS 2014 dataset (`2014.csv`).
* Filtered out invalid, refused, or missing survey responses (excluding specific code values such as 88.0 and other outliers).
* Cleaned and sorted the data for accurate frequency analysis.

## 📊 Visualization
* Generated bar charts to visualize the distribution of mental health values among respondents after filtering.
